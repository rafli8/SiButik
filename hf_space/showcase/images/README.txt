# Folder `images/`

Taruh file PNG hasil generate fusion batik di folder ini dengan nama:

- `madura_jawa_barat.png`
- `madura_pola_kompleks_jawa_barat.png`
- `madura_jawa_tengah.png`
- `madura_yogyakarta.png`

Jika Anda ingin menambah pasangan lain:
1. Taruh file PNG di folder ini
2. Edit `index.html` di parent folder, tambahkan `<div class="card">...</div>`
   untuk pasangan baru di dalam `<div class="grid">`

Cara generate gambar asli lihat `PANDUAN_STATIC.md` atau `PANDUAN_LOKAL.md`.
