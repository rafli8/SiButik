# Folder `descriptions/`

Folder ini berisi narasi markdown penjelasan untuk tiap fusion.
Saat ini narasi sudah inline di `index.html`, tapi folder ini
disediakan agar Anda bisa menambahkan penjelasan panjang
per fusion yang di-link dari card di gallery.

Format penamaan: `<daerah1>_<daerah2>.md`
